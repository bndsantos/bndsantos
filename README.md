# Olá, eu sou o Bruno! 👋

Sou desenvolvedor Java focado na criação de plugins e sistemas para servidores Minecraft.

Trabalho principalmente com Paper, Velocity, MySQL e integrações entre múltiplos servidores. Atualmente estou desenvolvendo uma suíte de plugins pensados para funcionar juntos dentro de uma network.

## 🧑‍💻 Sobre mim

- ☕ Desenvolvedor Java
- 🧱 Desenvolvimento de plugins Paper/Spigot
- 🌐 Networks utilizando Velocity
- 🗄️ MySQL, MariaDB e dados compartilhados
- 🎮 Compatibilidade com Java e Bedrock
- 🔗 APIs REST, webhooks e integrações externas
- 🧪 Gradle, JUnit 5 e testes automatizados

## 📦 Projetos

### MundoCore

Núcleo dos meus plugins. Ele gerencia a conexão com o banco de dados e disponibiliza serviços compartilhados entre os servidores da network.

### MundoLobby

Sistema de lobby com menus, seletor de servidores, tablist, itens interativos e preferências dos jogadores.

### MundoClans

Sistema de clans compartilhado entre todos os servidores, com membros, cargos, convites, alianças e dados persistentes.

### MundoNetworkUTILS

Conjunto de utilitários para a network, incluindo um sistema de punições globais integrado ao proxy e aos servidores Paper.

### MundoCart

Sistema de compras dentro do Minecraft com pagamento PIX, QR Code renderizado em mapas e entrega automática após a confirmação.
